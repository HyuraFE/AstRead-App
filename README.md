# AstRead (Native Android Edition)

Modern, 100% offline-first Book & Light Novel Tracker built natively with **Kotlin 2.0**, **Jetpack Compose**, and **Room Database**.

---

## Tech Stack

- **UI:** Jetpack Compose + Material 3 (Editorial Dark Theme: Midnight Espresso & Warm Gold)
- **Database:** Room Database (SQLite Native, Zero Backend, Zero Auth)
- **Architecture:** MVVM + Clean Architecture + StateFlow
- **CI/CD:** GitHub Actions (Build APK otomatis setiap kali push)
- **App ID:** `fun.pylexia.astread`

---

## Cara Dapatkan APK dari GitHub Actions

1. Push perubahan kode ke repository ini di branch `main`.
2. Buka tab **Actions** di repositori GitHub kamu.
3. Klik workflow run terbaru, lalu download file **AstRead-APK** di bagian *Artifacts*.
